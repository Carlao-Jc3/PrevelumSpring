# PrevelumSpring

Sistema web desenvolvido como parte do Projeto Integrador (PI), utilizando Spring Boot, Spring REST, JPA e MySQL.

## 📋 Sobre o projeto

O Prevelum é um sistema para gerenciamento de produtos, permitindo realizar operações de cadastro, consulta, pesquisa e exclusão de produtos.

O projeto foi desenvolvido a partir da aplicação desktop trabalhada nas etapas anteriores do Projeto Integrador e posteriormente adaptado para uma aplicação web.

## 🚀 Tecnologias utilizadas

- Java 17
- Spring Boot 4.0.7
- Spring REST
- Spring Data JPA
- Hibernate
- MySQL
- HTML5
- CSS3
- JavaScript
- Maven
- Git e GitHub
- NetBeans
